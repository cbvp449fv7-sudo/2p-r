# موقع أريج شاولي للخياطة

موقع كتالوج ثابت (static) باللغة العربية واتجاه RTL، الطلب فيه يتم عبر الواتساب مباشرة —
بدون سلة شراء وبدون بوابة دفع.

---

## كيف أضيف تصميمًا جديدًا؟ (بدون برمجة)

كل التصاميم في ملف واحد فقط: **`data/products.js`**

1. صوّري القطعة، وسمّي الصورة باسم إنجليزي بدون مسافات — مثلًا `as-06-green-floral.jpg`
2. ضعي **نسختين** من الصورة داخل `assets/images/products/`:
   - `as-06-green-floral.jpg` بعرض 1000 بكسل
   - `as-06-green-floral-sm.jpg` بعرض 500 بكسل
   (النسبة ٤:٥ — أي أن الطول = العرض × ١٫٢٥)
3. افتحي `data/products.js`، انسخي أي بلوك تصميم كامل والصقيه، ثم غيّري القيم:
   - `code` رمز التصميم (يظهر في رسالة الواتساب)
   - `cat` القسم: `prayer` أو `turban` أو `scarf`
   - `img` اسم الصورة **بدون** `.jpg` و**بدون** `-sm`
   - `price` اتركيه `''` ليظهر «السعر عبر الواتساب»
   - `sold` اجعليه `true` إذا نفد التصميم

لتغيير رقم الواتساب أو حساب إنستقرام أو رابط اليوتيوب: آخر جزء من نفس الملف (`window.BRAND`).

> لتوليد المقاسين من صورة واحدة بسرعة، استخدمي `scripts/prepare-images.py` (اشرحها بالأسفل).

## تشغيل الموقع محليًا

```bash
npm run serve      # ثم افتحي http://localhost:8080
```

## تعديل التصميم (للمطوّر)

الأنماط مبنية بـ Tailwind. ملف `assets/css/site.css` **مبني ومرفوع في المستودع**،
فلا حاجة لأي خطوة بناء عند النشر. عند تعديل أي كلاس في HTML:

```bash
npm install
npm run build      # أو npm run watch أثناء التطوير
```

## النشر

الموقع ملفات ثابتة فقط — ارفعيه كما هو على أي استضافة:
GitHub Pages أو Netlify أو Cloudflare Pages أو أي استضافة عادية. لا يحتاج خادمًا ولا قاعدة بيانات.

## البنية

```
index.html          الصفحة الرئيسية
products.html       كل التصاميم + التصفية حسب القسم
sizes.html          دليل المقاسات + نموذج يبني رسالة واتساب جاهزة
data/products.js    ← التصاميم وبيانات التواصل (الملف الوحيد الذي تعدّلينه عادة)
assets/js/site.js   منطق الموقع (بدون أي مكتبات خارجية)
assets/css/site.css ملف الأنماط المبني
assets/images/      الصور
scripts/            أدوات مساعدة
```

## ⚠️ يحتاج تأكيدًا من العميلة قبل الإطلاق

الأمور التالية **لم تُكتب في الموقع** لأننا لا نعرفها بعد — لا تُنشر الصفحة قبل حسمها:

| البند | الوضع الحالي في الموقع |
|---|---|
| الأسعار | تظهر «السعر عبر الواتساب» لكل تصميم |
| التوصيل ومناطق الشحن | **غير مذكور إطلاقًا** — يُضاف بعد تأكيدها |
| مدة التنفيذ | **غير مذكورة** |
| سياسة الاسترجاع | **غير مذكورة** (منصة «معروف» تتطلب توضيحها عادة) |
| المدينة | **غير مذكورة** |
| نوع القماش لكل تصميم | حقل `fabric` فارغ فلا يظهر السطر |
| رابط قناة اليوتيوب | فارغ، فتختفي الأيقونة تلقائيًا من الموقع |
| صور التوربان وطرح الحجاب | القسمان موجودان لكن بلا صور — تظهر رسالة «قيد التصوير» |

كذلك: أسماء التصاميم وأوصافها كُتبت **اعتمادًا على الصور فقط**، فيُستحسن أن تراجعها أريج
وتصحّح أي وصف للقماش أو التفاصيل.
