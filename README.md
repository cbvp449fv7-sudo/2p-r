# موقع أريج شاولي للخياطة

موقع كتالوج ثابت (static) عربي باتجاه RTL. الطلب يتم عبر الواتساب مباشرة —
بدون سلة شراء وبدون بوابة دفع.

---

## 🚀 التشغيل السريع

```bash
npm install      # مرة واحدة فقط
npm start        # يبني الموقع ويشغّله على http://localhost:8080
```

| الأمر | ماذا يفعل |
|---|---|
| `npm run build` | يبني الأنماط والصفحات — **شغّليه بعد أي تعديل على البيانات** |
| `npm run check` | يفحص بيانات المنتجات فقط، بدون بناء |
| `npm run serve` | يشغّل الموقع محليًا |
| `npm run validate:html` | يفحص صحّة HTML |

## ✏️ كيف أضيف تصميمًا جديدًا؟

### ١. جهّزي الصورة

```bash
python3 scripts/prepare-images.py صورتك.jpg as-06-green-floral
```

ينتج تلقائيًا كل المقاسات والصيغ المطلوبة (JPEG و WebP و AVIF، بحجمين).

### ٢. أضيفي التصميم إلى `data/products.js`

انسخي أي بلوك كامل والصقيه، ثم غيّري القيم. الحقول مشروحة داخل الملف نفسه.

### ٣. ابنِ الموقع

```bash
npm run build
```

> **مهم:** الصفحات مبنية مسبقًا — لهذا يظهر الموقع لمحرّكات البحث ويعمل حتى لو
> تعطّل الجافاسكربت. لكن هذا يعني أن التصميم الجديد **لن يظهر قبل تشغيل `npm run build`**.
> إن نسيتِ، يظهر لك تنبيه أحمر عند التصفّح المحلي يذكّرك بذلك.

البناء **يرفض** المتابعة إذا كان هناك خطأ في البيانات، ويخبرك بالسطر بالضبط:
رمز مكرّر، صورة ناقصة، قسم غير معرّف، لون غير صالح، أو نص بديل ناقص.

### تعديل بيانات التواصل أو النشاط

كلها في ملف واحد: **`data/business.js`**.

## ⚠️ قائمة ما قبل الإطلاق — معلومات ناقصة

القاعدة في هذا المشروع: **لا تُخترع أي معلومة عن النشاط.**
أي حقل قيمته `null` في `data/business.js` يعني «غير مؤكّد»، والموقع يُخفي القسم
المرتبط به تلقائيًا بدل عرض معلومة غير صحيحة.

| # | المعلومة | الحقل | وضعها الآن في الموقع |
|---|---|---|---|
| 1 | **الأسعار** | `price` في كل منتج | يظهر «يُحدَّد بعد تأكيد التصميم والمقاس» |
| 2 | **نوع القماش لكل تصميم** | `fabric` | السطر مخفي تمامًا. **لا تُخمَّن من الصورة** |
| 3 | **مدة التنفيذ** | `productionDays` | «تخبرك أريج بالمدة المتوقّعة قبل أن تبدأ» |
| 4 | **مناطق التوصيل** | `delivery.areas` | «تتفقان على طريقة الاستلام داخل المحادثة» |
| 5 | **رسوم الشحن** | `delivery.cost` | غير مذكورة |
| 6 | **طرق الدفع** | `payment` | غير مذكورة — يظهر سؤال في الأسئلة الشائعة عند تعبئته |
| 7 | **التعديلات بعد الاستلام** | `alterations` | غير مذكورة |
| 8 | **الاستبدال والاسترجاع** | `returns` | غير مذكورة — **منصة «معروف» تتوقّع ذكرها** |
| 9 | **المدينة** | `city` | غير مذكورة |
| 10 | **تعليمات العناية** | `care` في كل منتج | السطر مخفي |
| 11 | **نطاق الموقع** | `domain` | بدونه لا يُنشأ `sitemap.xml` وتكون روابط المشاركة نسبية |
| 12 | **رابط اليوتيوب** | `youtube` | الأيقونة تختفي من الموقع |
| 13 | **المراجعات** | `reviews` | القسم **مخفي بالكامل**. لا تُضاف مراجعة غير حقيقية |

### يحتاج تصويرًا من المالكة

- **صور التوربان وطرح الحجاب** — القسمان معلَّمان «قريبًا» الآن، وهذا صادق،
  لكن الموقع لن يبيعهما قبل وصول الصور. حوّلي `status` إلى `'available'` في
  `data/products.js` بعد إضافة أول تصميم.
- **صور تفصيلية لكل قطعة** — الأكمام، السحّاب، الدانتيل، القماش عن قرب.
  صفحة المنتج جاهزة لمعرض صور متعدّد؛ تكفي إضافتها في `images`.
- **صور من الورشة** — القماش، الماكينة، القص. قسم «عن أريج» يحتاجها ليكون
  إثباتًا بصريًا للحرفة لا نصًّا فقط.
- **أسماء التصاميم وأوصافها** كُتبت اعتمادًا على الصور. يُستحسن أن تراجعها أريج.

## 🎬 المقدّمة (intro)

مقدّمة قصيرة (~٥ ثوانٍ) تظهر على الصفحة الرئيسية فقط: قماش يتموّج ← غرزة تُخاط ←
القماش يتجمّع ← علامة أريج ← الصفحة. مرسومة على canvas بدون أي مكتبة خارجية.

**لا تظهر إطلاقًا** في هذه الحالات — القرار يُتّخذ قبل أول رسم:

| الحالة | النتيجة |
|---|---|
| المستخدمة تفضّل تقليل الحركة | تُتخطّى |
| زارت الموقع في نفس الجلسة | تُتخطّى |
| اتصال بطيء أو «توفير البيانات» | تُتخطّى |
| فتحت رابطًا بعلامة `#` | تُتخطّى |
| جهاز ضعيف (نواتان أو ذاكرة ≤ ١ غيغا) | نسخة ثابتة بالعلامة فقط، بلا رسم |
| الجافاسكربت معطّل | لا توجد طبقة أصلًا — الصفحة كاملة |

**للتحكّم أثناء التجربة:** `?intro=1` تفرض العرض · `?intro=0` تمنعه.

**لإيقافها نهائيًا:** احذفي سطر `INTRO_GATE` و`INTRO_SCRIPT` من استدعاء الصفحة
الرئيسية في `build.mjs`، ثم `npm run build`. الموقع يعمل كما هو بدونها.

**الملفات:** `assets/js/intro.js` (٤٫٣ ك.ب مضغوطة) + قسم في `assets/css/tailwind.css`
+ بوّابة صغيرة داخل `<head>`.

> طبقة الرسم معزولة في دالة `createClothRenderer`. تبديلها إلى WebGL لا يمسّ بقية
> الملف — راجعي `docs/identity-contract.md` §8 لسبب اختيار canvas بدل Three.js.

## 🌐 النشر

الموقع ملفات ثابتة. ارفعي المجلد كما هو على GitHub Pages أو Netlify أو
Cloudflare Pages أو أي استضافة عادية. لا يحتاج خادمًا ولا قاعدة بيانات.

**قبل النشر:** اضبطي `domain` في `data/business.js` ثم `npm run build`
لتوليد `sitemap.xml` والروابط المطلقة.

**إعدادات الكاش المقترحة على الخادم:**

```
/assets/images/*   Cache-Control: public, max-age=31536000, immutable
/assets/css/*      Cache-Control: public, max-age=604800
/assets/js/*       Cache-Control: public, max-age=604800
/*.html            Cache-Control: public, max-age=0, must-revalidate
```

## ✅ ما تم التحقّق منه فعليًا

فُحص في متصفّح حقيقي (Chromium) وليس بالقراءة:

- **axe-core** على الصفحات الأربع بمعايير WCAG 2.0/2.1/2.2 A و AA → **صفر مخالفات**
- **html-validate** على كل الصفحات المبنية → **صفر أخطاء**
- **التباين:** كل نص فُحص مقابل خلفيته الفعلية → صفر إخفاقات دون 4.5:1
- **لا تمرير أفقي** عند 375 و390 و768 و1440 بكسل
- **إعادة التدفّق** عند تكبير 200% و400% (أي عرض 640 و320 بكسل) → سليمة
- **بدون جافاسكربت:** الصفحات والمنتجات وروابط الطلب تظهر كاملة
- **لوحة المفاتيح:** تخطّي المحتوى، الوصول لزر الطلب في ٦ خطوات، حلقة تركيز ظاهرة
- **القائمة:** تفتح، ينتقل التركيز إليها، تُغلق بـ Escape وبالضغط خارجها، ويعود التركيز للزر
- **الصور:** صفر صور مكسورة على كل الصفحات
- **حركة مخفَّضة:** `prefers-reduced-motion` محترم
- **التحقّق من البيانات:** جُرِّب برمز مكرّر، صورة ناقصة، قسم خاطئ، لون غير صالح،
  نص بديل ناقص، وحقل مطلوب فارغ — كلها أوقفت البناء برسالة واضحة

### المقدّمة تحديدًا

- **التسليم:** لقطة المقدّمة الأخيرة مطابقة **بكسل ببكسل** للصفحة بلا مقدّمة —
  أي أن الواجهة لا تقفز ولا تتحرّك عند انتهائها
- **الحالات المُختبَرة:** التحميل · نجاح البدء · فشل تحميل `intro.js` (مؤقّت أمان
  يحرّر الصفحة) · فشل تحميل الشعار (الاسم وحده يظهر) · canvas غير مدعوم ·
  تقليل الحركة · جهاز ضعيف · التخطّي بعد ١٥٠ مللي · Escape · زيارة ثانية في نفس
  الجلسة · إخفاء التبويب (تتوقّف الحركة تمامًا) · تغيير المقاس أثناء العرض ·
  الاكتمال الطبيعي · الجافاسكربت معطّل — **كلها تنتهي بالصفحة الطبيعية**
- **التنظيف:** صفر إطارات رسم بعد الانتهاء، اللوحة محذوفة، المستمعات مُزالة،
  التمرير مُعاد، التركيز ينتقل إلى المحتوى
- **الوصولية:** صفر مخالفات axe **أثناء** عرض المقدّمة وبعدها
- **الأجهزة:** ثلاث مستويات فعليًا مختلفة (جوال/لوحي/مكتب) — تحقّقنا من اختلاف
  دقّة الرسم والطيّ، لا مجرّد تصغير
- **الوزن:** أضافت ٤٫١ ك.ب مضغوطة (١٣٫٥ → ١٧٫٦ ك.ب)

**لم يُختبر:** قارئ شاشة حقيقي (VoiceOver / NVDA) — غير متوفّر في بيئة العمل.
البنية الدلالية وأسماء العناصر صحيحة، لكن التجربة الفعلية تحتاج اختبارًا بشريًا.
